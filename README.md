# FreeOS

FreeOS is a no-cost operating-system project intended to be practical for broad use, including commercial environments.

## Project direction

- **No-cost to obtain.** “Free” describes the intended price to users; it does not mean every included component must be free software.
- **Commercial-friendly project code.** The original FreeOS project code in this repository is licensed under the MIT License. See [LICENSE](LICENSE).
- **Proprietary components may be considered.** Unlike OpenOS, FreeOS may include or offer proprietary drivers and other proprietary components when useful, including vendor-provided GPU drivers, subject to their license terms and redistribution permissions.
- **Be transparent.** Proprietary components should be identified clearly, kept distinct from open-source components where practical, and distributed only when their terms permit it.
- **Respect upstream licenses.** The MIT license applies to this repository's project code; it does not change the licenses or terms of third-party software, drivers, firmware, or applications.

## Relationship to OpenOS

FreeOS and OpenOS have different software-admission policies. OpenOS is intended to exclude proprietary software and proprietary drivers. FreeOS is more permissive about including proprietary components when they provide useful hardware support or functionality.
